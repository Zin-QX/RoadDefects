## 接口文档

### 公共响应格式

所有接口的响应格式统一为：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，0 表示成功 |
| data | Object | 返回的数据 |
| message | String | 响应消息 |

### 认证说明

系统采用 **JWT (JSON Web Token)** 进行身份认证：

1. **登录成功后**：服务端返回 JWT token
2. **后续请求**：需在请求头 `Authorization` 中携带 token
3. **token 格式**：`Bearer <token>`

**需要认证的接口**：
- 获取当前登录用户信息
- 上传图片（仅微信用户）
- 所有管理员接口（需 admin 角色）

### 一、微信用户接口

#### 1. 微信登录

**接口**: `POST /wxuser/login`

**说明**: 微信用户使用 code 登录，自动注册新用户并返回 token

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| code | String | 是 | 微信登录凭证（小程序端获取） |

**响应数据**:

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 表示成功 |
| data | AuthorizationVO | 授权信息 |
| message | String | 响应消息 |

**AuthorizationVO 对象**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 授权记录 ID |
| openid | String | 微信 openid |
| token | String | JWT 令牌 |

**示例**:
```json
{
  "code": 0,
  "data": {
    "id": 1234567890,
    "openid": "oXXXX-xxxx-xxxx-xxxx",
    "token": "eyJhbGciOiJIUzI1NiJ9.xxxxx"
  },
  "message": "ok"
}
```

### 三、图片接口

#### 12. 上传图片（仅微信用户）

**接口**: `POST /picture/upload`

**说明**: 
- **仅微信用户可用**（需在 authorization 表有记录）
- 需要携带 token
- 如果传入 `id`，系统会根据经纬度计算距离：
  - 如果距离小于 3 米，认为是同一张图片，执行更新操作
  - 如果距离大于等于 3 米，认为是新图片，执行新增操作
- 如果 `id` 为空，直接新增图片

**请求头**: `Authorization: Bearer <token>`

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | MultipartFile | 是 | 图片文件 |
| id | Long | 否 | 图片 ID（用于更新） |
| longitude | Double | 是 | 经度 |
| latitude | Double | 是 | 纬度 |
| address | String | 否 | 地址 |

**响应数据**:

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 表示成功 |
| data | PictureVO | 上传的图片信息 |
| message | String | 响应消息 |

**PictureVO 对象**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 图片 ID |
| url | String | 图片 URL |
| name | String | 图片名称 |
| longitude | Double | 经度 |
| latitude | Double | 纬度 |
| address | String | 地址 |
| picSize | Long | 文件大小（字节） |
| userId | Long | 创建用户 ID |
| createTime | Date | 创建时间 |
| editTime | Date | 编辑时间 |
| updateTime | Date | 更新时间 |

### 四、距离计算策略

#### Vincenty 公式（椭球面距离计算）

**类**: `DistanceCalculateOfVincentyUtil`

**方法**: `calculateDistance(double lng1, double lat1, double lng2, double lat2)`

**参数说明**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| lng1 | double | 点 1 经度 |
| lat1 | double | 点 1 纬度 |
| lng2 | double | 点 2 经度 |
| lat2 | double | 点 2 纬度 |

**返回值**: `double` - 两点间距离（单位：米）

**精度**: 理论计算结果精度可达到 1 米内

---

#### Haversine 公式（球面距离计算）

**类**: `HaversineFormula`

**方法**: `calculateDistance(double lng1, double lat1, double lng2, double lat2)`

**参数说明**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| lng1 | double | 点 1 经度 |
| lat1 | double | 点 1 纬度 |
| lng2 | double | 点 2 经度 |
| lat2 | double | 点 2 纬度 |

**返回值**: `double` - 两点间距离（单位：千米）

**精度**: 约 0.5%，适合一般应用场景

### 六、使用示例

#### 微信用户登录并上传图片

```javascript
// 1. 微信登录
const loginResponse = await fetch('/api/wxuser/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ code: 'wx_code_here' })
});
const { token } = await loginResponse.json();

// 2. 上传图片
const formData = new FormData();
formData.append('file', imageFile);
formData.append('longitude', '116.4074');
formData.append('latitude', '39.9042');
formData.append('address', '北京市朝阳区');

const uploadResponse = await fetch('/api/picture/upload', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`
  },
  body: formData
});
```

#### 普通用户登录并获取信息

```javascript
// 1. 账号密码登录

// 2. 获取当前用户信息

  headers: {
    'Authorization': `Bearer ${token}`
  }
```
