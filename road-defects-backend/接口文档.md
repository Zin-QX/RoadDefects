## 接口文档

### 公共响应格式

所有接口的响应格式统一为：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，0 表示成功 |
| data | Object | 返回的数据 |
| message | String | 响应消息 |

### 认证说明

系统采用 **JWT (JSON Web Token)** 进行身份认证：

1. **登录成功后**：服务端返回 JWT token
2. **后续请求**：需在请求头 `Authorization` 中携带 token
3. **token 格式**：`Bearer <token>`

**需要认证的接口**：
- 获取当前登录用户信息
- 上传图片（仅微信用户）
- 所有管理员接口（需 admin 角色）

### 三、图片接口

#### 13. 上传图片

**接口**: `POST /picture/upload`

**说明**: 
- 需要携带 token
- 支持新增和更新图片
- **自动调用 Python AI 接口进行图片处理**
  - 上传成功后自动调用 `http://localhost:8000/detect` 接口
  - 将图片 ID、URL 和用户 ID 发送给 Python 服务
  - Python 服务可根据用户 ID 区分用户文件目录
  - 接收处理后的图片 URL 和处理结果
  - 自动更新到数据库的 `processedUrl` 和 `processedResult` 字段
- 如果传入 `id`，系统会根据经纬度计算距离：
  - 如果距离小于 5 米，认为是同一张图片，执行更新操作
  - 如果距离大于等于 5 米，抛出异常

**请求头**: `Authorization: Bearer <token>`

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | MultipartFile | 是 | 图片文件（最大 10MB） |
| id | Long | 否 | 图片 ID（用于更新） |
| longitude | Double | 是 | 经度 |
| latitude | Double | 是 | 纬度 |
| address | String | 否 | 地址 |

**响应数据**:

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 表示成功 |
| data | PictureVO | 上传的图片信息 |
| message | String | 响应消息 |

**PictureVO 对象**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 图片 ID |
| url | String | 原始图片 URL |
| name | String | 图片名称 |
| longitude | Double | 经度 |
| latitude | Double | 纬度 |
| address | String | 地址 |
| processedUrl | String | **处理后的图片 URL**（AI 标注结果） |
| processedResult | List<String> | **处理结果列表**（缺陷检测描述，数据库存储为 JSON 字符串，接口返回为列表） |
| picSize | Long | 文件大小（字节） |
| userId | Long | 创建用户 ID |
| createTime | Date | 创建时间 |
| updateTime | Date | 更新时间 |

**processedResult 示例**:
```json
{
  "processedResult": [
    "修补裂缝(置信度:76.64%)",
    "修补网裂(置信度:39.26%)"
  ]
}
```

**Python 接口调用说明**:

- **请求格式**: JSON
- **请求参数**:
  ```json
  {
    "id": 2034196409431478274,
    "url": "https://zinqx-1391992760.cos.ap-guangzhou.myqcloud.com/RoadDefects/xxx.jpg",
    "userId": 1234567890
  }
  ```
- **返回格式**:
  ```json
  {
    "id": 2034196409431478274,
    "processedUrl": "https://zinqx-1391992760.cos.ap-guangzhou.myqcloud.com/road-defects/processed.jpg",
    "processedResult": "[\"修补裂缝(置信度:76.64%)\", \"修补网裂(置信度:39.26%)\"]"
  }
```

### 四、距离计算策略

#### Vincenty 公式（椭球面距离计算）

**类**: `DistanceCalculateOfVincentyUtil`

**方法**: `calculateDistance(double lng1, double lat1, double lng2, double lat2)`

**参数说明**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| lng1 | double | 点 1 经度 |
| lat1 | double | 点 1 纬度 |
| lng2 | double | 点 2 经度 |
| lat2 | double | 点 2 纬度 |

**返回值**: `double` - 两点间距离（单位：米）

**精度**: 理论计算结果精度可达到 1 米内

---

#### Haversine 公式（球面距离计算）

**类**: `HaversineFormula`

**方法**: `calculateDistance(double lng1, double lat1, double lng2, double lat2)`

**参数说明**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| lng1 | double | 点 1 经度 |
| lat1 | double | 点 1 纬度 |
| lng2 | double | 点 2 经度 |
| lat2 | double | 点 2 纬度 |

**返回值**: `double` - 两点间距离（单位：千米）

**精度**: 约 0.5%，适合一般应用场景

### 五、错误码

|--------|------|

| 5000 | 操作失败 |

**业务错误说明**:

| 场景 | 说明 |
|------|------|

| 审核状态 | 0-待审核，1-道路有异常，2-道路无异常，3-拒绝通过 |
