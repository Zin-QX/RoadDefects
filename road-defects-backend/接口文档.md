### 图片接口

#### 11. 上传图片（仅管理员）

**接口**: `POST /picture/upload`

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | MultipartFile | 是 | 图片文件 |
| id | Long | 否 | 图片ID（用于更新） |
| longitude | Double | 否 | 经度 |
| latitude | Double | 否 | 纬度 |
| address | String | 否 | 地址 |

**说明**:
- 如果传入 `id`，系统会根据经纬度计算距离：
  - 如果距离小于3米，认为是同一张图片，执行更新操作
  - 如果距离大于等于3米，认为是新图片，执行新增操作
- 如果 `id` 为空，直接新增图片

**响应数据**:

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0表示成功 |
| data | PictureVO | 上传的图片信息 |
| message | String | 响应消息 |

**PictureVO 对象**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 图片ID |
| url | String | 图片URL |
| name | String | 图片名称 |
| longitude | Double | 经度 |
| latitude | Double | 纬度 |
| address | String | 地址 |
| picSize | Long | 文件大小（字节） |
| picWidth | Integer | 图片宽度 |
| picHeight | Integer | 图片高度 |
| picScale | Double | 图片比例 |
| picFormat | String | 图片格式（如：jpg、png） |
| userId | Long | 创建用户ID |
| createTime | Date | 创建时间 |
| editTime | Date | 编辑时间 |
| updateTime | Date | 更新时间 |

### 距离计算策略

#### Vincenty 公式（椭球面距离计算）

**类**: `DistanceCalculateOfVincentyUtil`

**方法**: `calculateDistance(double lng1, double lat1, double lng2, double lat2)`

**参数说明**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| lng1 | double | 点1经度 |
| lat1 | double | 点1纬度 |
| lng2 | double | 点2经度 |
| lat2 | double | 点2纬度 |

**返回值**: `double` - 两点间距离（单位：米）

**精度**: 理论计算结果精度可达到1米内

---

#### Haversine 公式（球面距离计算）

**类**: `HaversineFormula`

**方法**: `calculateDistance(double lng1, double lat1, double lng2, double lat2)`

**参数说明**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| lng1 | double | 点1经度 |
| lat1 | double | 点1纬度 |
| lng2 | double | 点2经度 |
| lat2 | double | 点2纬度 |

**返回值**: `double` - 两点间距离（单位：千米）

**精度**: 约0.5%，适合一般应用场景
